Como jogar

Abra todas as casas sem minas. Os números indicam quantas minas estão nas oito casas vizinhas. Use o botão direito ou o modo bandeira para marcar uma suspeita.

No teclado, use as setas para navegar, Enter ou Espaço para abrir e F para colocar uma bandeira. O cronômetro começa na primeira casa aberta e para durante a pausa.
